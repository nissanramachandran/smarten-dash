 EduFlow Dashboard

A modern student learning dashboard built for a Frontend Internship Assignment.

## Features

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion Animations
- Supabase Database Integration
- Bento Grid Dashboard
- Dark Mode UI
- Responsive Design
- Animated Progress Bars
- Sidebar Navigation
- Dynamic Course Management

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase
- Lucide React

## Database

Courses are fetched dynamically from Supabase.

Table: courses

Columns:
- id
- title
- progress
- icon_name
- created_at

## Installation

bash
npm install
npm run dev


## Deployment

Deployed using Vercel.
